# 战姬角色卡 — 文件结构说明

## 根目录文件

| 文件 | 功能 |
|---|---|
| `index.yaml` | 角色卡主配置：世界书条目索引、正则规则（变量更新折叠/去格式化）、酒馆助手脚本库注册（mvu、变量结构、任务系统）、状态栏界面注入 |
| `schema.ts` | MVU 变量结构定义文件，包含完整 Zod Schema + 计算逻辑（等级/属性/日常结算等）。供 `pnpm build` 生成 `schema.json` 及脚本/界面导入使用。已与 JSON 脚本同步 |
| `schema.json` | `schema.ts` 的构建产物（`pnpm build` 生成），用于 initvar 的 `$schema` 校验 |
| `酒馆助手脚本-变量结构 (1).json` | **【实际生效的变量结构脚本】** 从酒馆助手导出的完整脚本，包含全部 Schema 定义、计算逻辑（等级/属性/日常结算）和 `registerMvuSchema` 注册调用 |

## 脚本/

### 脚本/变量结构/

| 文件 | 功能 |
|---|---|
| `变量结构.yaml` | **【参考副本】** 从酒馆助手脚本中复制出的代码内容（yaml格式包裹），用于可读性参考。已与 JSON 脚本同步（含 `_任务奖励映射` 和 `_任务上次刷新日期`） |

### 脚本/任务系统/

| 文件 | 功能 |
|---|---|
| `index.ts` | 任务系统脚本：监听 `VARIABLE_UPDATE_ENDED` 事件，自动刷新每日/周常任务（日期变更时）、检测任务完成并发放奖励（金币+道具）。任务模板池：日常 20 个 + 周常 15 个 |

### 脚本/战斗系统/

| 文件 | 功能 |
|---|---|
| `index.ts` / `App.vue` | 战斗系统前端入口 |
| `engine.ts` | 战斗引擎核心逻辑 |
| `store.ts` | Pinia 战斗状态管理 |
| `types.ts` | 战斗系统类型定义 |
| `anim.ts` | 战斗动画 |
| `useBattleCommand.ts` | 战斗指令处理 |
| `global.css` | 战斗界面样式 |
| `components/BattleArena.vue` | 战斗场地组件 |
| `components/BattleResultModal.vue` | 战斗结果弹窗 |
| `components/SkillPanel.vue` | 技能面板组件 |
| `components/TurnOrderBar.vue` | 回合顺序条组件 |
| `components/ItemSelect.vue` | 道具选择组件 |

### 脚本/MVU/

| 文件 | 功能 |
|---|---|
| `index.ts` | MVU 框架加载入口 |

## 界面/

### 界面/战斗前端/

| 文件 | 功能 |
|---|---|
| `index.ts` / `App.vue` | 战斗前端入口 |
| `store.ts` | 战斗前端 Pinia store |

### 界面/状态栏/

| 文件 | 功能 |
|---|---|
| `zhanji.md` | 状态栏设计说明 |
| `zhanji.yaml` | **状态栏主文件**：包含完整 HTML/CSS/JS，实现 5 个标签页（战姬列表、训练家、背包、任务、商店）。商店含硬编码道具列表和购买逻辑（`updateVariablesWith` 直接写变量） |
| `index.html` | 状态栏入口页面 |
| `regex-手机态栏.json` | 手机端状态栏正则配置 |
| `working_backup.html` | 工作备份 |

## 世界书/

### 世界书/变量/

| 文件 | 功能 |
|---|---|
| `initvar.yaml` | 变量初始化值（当前为空 `{}`，等待通过 `schema.json` 填充初始值） |
| `变量列表.txt` | 变量列表模版：`{{format_message_variable::stat_data}}`，用于在提示词中展示当前变量状态 |
| `变量输出格式.yaml` | AI 输出变量更新的格式规范：`<UpdateVariable>` + `<Analysis>` + `<JSONPatch>` 标准格式 |
| `变量更新规则.yaml` | **变量增量更新规则**：定义每个变量路径的类型、范围、check 条件和更新逻辑。AI 必须按此规则输出 JSON Patch |
| `战后裁决.yml` | 战斗结束后裁决/结算相关规则 |
| `战斗技能引擎对齐检查清单.md` | 技能引擎与规则对齐检查 |
| `角色更新规则.yml` | 角色数据更新规则 |
| `技能原则.yaml` | 技能生成原则 |

### 世界书/（根目录）

| 文件 | 功能 |
|---|---|
| `----战姬捕捉系统1.4 (2).json` | 战姬捕捉系统的世界书条目导出文件 |
| `renwu.txt` | 任务系统 AI 指令：定义 AI 在任务系统中的职责（查看/更新进度/完成判定）、禁止事项和输出格式 `<quest_panel>` |
| `daoju.txt` | 道具参考：AI 可操作的高级道具列表，区分基础道具（脚本/商店管理）和高级稀有道具（AI 可灵活发放） |
