# AI 角色技能生成限制说明

> 本文档用于约束 AI 生成角色技能时的边界，确保生成的技能能被战斗引擎正确执行。**违反以下规则生成的技能将无法在战斗系统中运行。**

---

## 一、技能基础结构

每个技能必须包含以下字段（`SkillData` 接口）：

```typescript
{
  name: string;           // 技能名称
  类型: '主动' | '被动' | '光环' | '天赋';  // 四选一
  稀有度: string;         // 'N' | '普通' | '稀有' | '史诗' | '传说' | '神话'
  元素属性: '地' | '火' | '水' | '风' | '光' | '暗' | '无';  // 七选一
  消耗MP: number;         // MP消耗（固定按稀有度：N=0, 普通=5, 稀有=12, 史诗=20, 传说=32, 神话=45）
  冷却回合: number;       // 冷却回合数（0=无冷却）
  基础威力: number;       // 基础威力值
  描述: string;           // 技能描述文本
  效果公式: string;       // 七选一，见下方
  目标类型?: string;      // 五选一，见下方
  数值参数: {};           // 参数对象，见下方
}
```

### 禁止事项

- ❌ **禁止自创新的 `效果公式` 值**。只能使用下方列出的 7 种。
- ❌ **禁止自创新的 `目标类型` 值**。只能使用下方列出的 5 种。
- ❌ **禁止自创新的 `元素属性` 值**。只能使用 地/火/水/风/光/暗/无。
- ❌ **禁止自创新的 `类型` 值**。只能使用 主动/被动/光环/天赋。
- ❌ **禁止自创新的异常状态类型**。只能使用下方列出的异常状态。
- ❌ **禁止使用不在 `数值参数` 列表中的参数名**。引擎会忽略未识别的参数。

---

## 二、效果公式（`效果公式`）—— 只允许以下 7 种

| 效果公式 | 说明 | 计算逻辑 |
|---|---|---|
| `physical_damage` | 物理伤害 | 使用 **攻击力 vs 防御力** 计算伤害 |
| `magic_damage` | 魔法伤害 | 使用 **特攻 vs 特防** 计算伤害 |
| `heal` | 治疗 | 恢复 HP，不可造成伤害 |
| `buff` | 增益 | 对目标施加正面状态（+数值） |
| `debuff` | 减益 | 对目标施加负面状态（-数值） |
| `drain_physical` | 物理吸血 | 物理伤害 + 按比例回复攻击者 HP |
| `drain_magic` | 魔法吸血 | 魔法伤害 + 按比例回复攻击者 HP |

### 禁止事项

- ❌ **禁止一个技能同时拥有两种效果公式**。例如不能同时造成 `physical_damage` 又施加 `heal`。吸血请用 `drain_physical` 或 `drain_magic`。
- ❌ **禁止自创公式**。例如不存在 `dot`、`shield_only`、`revive`、`mp_drain`、`reflect`、`counter`、`suicide` 之类的公式。
- ❌ **buff/debuff 公式不能造成直接伤害**。它们只修改属性，伤害为 0。
- ❌ **heal 公式不能造成伤害**。它只能恢复 HP。
- ❌ **不存在"复活"效果公式**。战斗引擎不支持复活已倒下的单位。
- ❌ **不存在"自爆/自伤"效果公式**。不能设计牺牲自己造成伤害的技能。
- ❌ **不存在"反射/反弹"效果公式**。不能设计反弹伤害的技能。

---

## 三、目标类型（`目标类型`）—— 只允许以下 5 种

| 目标类型 | 说明 |
|---|---|
| `single_enemy` | 单体敌人 |
| `self` | 自身 |
| `ally` | 单体友方 |
| `all_enemies` | 全体敌人（**注意：当前引擎实现中实际只命中当前出战敌人**，行为与 `single_enemy` 相同） |
| `all_allies` | 全体友方 |

### 禁止事项

- ❌ **`all_enemies` 当前引擎实现只命中当前出战敌人**，与 `single_enemy` 行为一致。全体 buff/heal 请用 `all_allies`（`all_allies` 有专门的全体逻辑）。
- ❌ **禁止指定"敌方后排/替补"为目标**。技能只能作用于当前出战单位。
- ❌ **禁止"随机目标"**。目标选择由玩家或 AI 决定，技能本身不能指定随机目标。
- ❌ **禁止"血量最低/最高的敌人"等条件目标**。引擎不支持条件自动选择目标。

---

## 四、数值参数（`数值参数`）—— 允许的参数名清单

引擎**只识别**以下参数名，未列出的参数会被**直接忽略**：

### 伤害相关
| 参数名 | 类型 | 说明 | 约束 |
|---|---|---|---|
| `伤害类型` | number | 0=物理, 1=魔法 | 仅 0 或 1 |
| `暴击率加成` | number | 额外暴击率 | 基础暴击率 6.25%，加成后上限 50% |
| `命中率` | number | 技能命中率 | 范围 0.35 ~ 1.0，默认 0.95 |
| `系数` | number | 技能系数 | 系数 > 0 时启用高系数公式，伤害上限更高 |
| `吸血比例` | number | 吸血回复比例 | 仅对 `drain_physical`/`drain_magic` 有效，默认 0.4 |

### 异常状态（仅对 `single_enemy` / `all_enemies` 目标有效）

| 参数名 | 类型 | 说明 |
|---|---|---|
| `灼烧概率` | number | 0~1 |
| `灼烧伤害` | number | 每回合扣除 HP 上限的比例（如 0.05 = 5%） |
| `灼烧回合` | number | 持续回合数 |
| `中毒概率` | number | 0~1 |
| `中毒伤害` | number | 每回合扣除 HP 上限的比例 |
| `中毒回合` | number | 持续回合数 |
| `冰冻概率` | number | 0~1 |
| `冰冻回合` | number | 持续回合数（冰冻期间无法行动） |
| `麻痹概率` | number | 0~1 |
| `麻痹回合` | number | 持续回合数（麻痹期间概率跳过行动） |
| `混乱概率` | number | 0~1 |
| `混乱回合` | number | 持续回合数（混乱期间概率自伤 6% HP） |

### BUFF/DEBUFF 属性加成（可正可负）

| 参数名 | 类型 | 说明 |
|---|---|---|
| `攻击加成` | number | 比例值，如 0.2 = +20% |
| `防御加成` | number | 比例值 |
| `特攻加成` | number | 比例值 |
| `特防加成` | number | 比例值 |
| `速度加成` | number | 比例值 |
| `命中加成` | number | 比例值（命中最终 clamp 0.6~1.8） |
| `闪避加成` | number | 比例值（闪避最终 clamp 0.6~1.8） |
| `持续回合` | number | buff/debuff/护盾 的持续回合数 |

### 治疗相关

| 参数名 | 类型 | 说明 |
|---|---|---|
| `治疗量` | number | 固定治疗值 |
| `治疗比例` | number | 按最大 HP 比例治疗，如 0.25 = 25% |

### 护盾相关

| 参数名 | 类型 | 说明 |
|---|---|---|
| `护盾值` | number | 固定护盾值 |
| `护盾比例` | number | 按最大 HP 比例加护盾 |

### 禁止事项

- ❌ **禁止使用以上列表之外的参数名**。例如 `破甲值`、`真实伤害`、`斩杀线`、`连击数`、`反击率` 等自定义参数不会被引擎识别。
- ❌ **buff 和 debuff 用同一组参数**（攻击加成等）。正值 = buff，负值 = debuff，由 `效果公式` 是 `buff` 还是 `debuff` 决定语义。
- ❌ **不存在"驱散"参数**。引擎不支持驱散敌方的 buff 或自身的 debuff。
- ❌ **不存在"伤害减免"参数**。只能通过提升 防御/特防 间接实现。
- ❌ **不存在"必定暴击"参数**。暴击率加成上限受 50% 总暴击率限制。
- ❌ **不存在"无视防御/真实伤害"参数**。所有伤害都经过防御减免计算。
- ❌ **不存在"偷取MP/回复MP"参数**。只有 强攻型 和 均衡型 的战斗类型被动支持 MP 回复。
- ❌ **不存在"禁止换人/束缚"类型的状态**。引擎只支持 灼烧/中毒/冰冻/麻痹/混乱 五种负面状态。

## 五、元素克制系统

```
火 → 克制 → 风
风 → 克制 → 地
地 → 克制 → 水
水 → 克制 → 火
光 ↔ 互克 ↔ 暗
无 → 无克制关系（对任何属性均为 1.0 倍率）
```

### 克制倍率
- 克制：**1.5x**（效果拔群）
- 被克制：**0.67x**（效果不佳）
- 同属性：**0.5x**（同属性抵消）
- STAB（技能属性=使用者属性）：额外 **1.35x**

### 禁止事项

- ❌ **禁止自创元素克制关系**。克制表是硬编码的，无法修改。
- ❌ **禁止创造"双属性"技能**。每个技能只有一个 `元素属性`。
- ❌ **禁止技能有"无视属性克制"效果**。克制计算无法被跳过。

---

## 六、被动技能限制

被动技能（`类型: '被动' | '天赋' | '光环'`）只能通过 `数值参数` 触发以下引擎行为：

### 引擎实际检查的被动效果

| 触发时机 | 引擎行为 |
|---|---|
| `on_attack`（攻击时） | 累加所有被动的 `暴击率加成` |
| `on_hit`（受击时） | 无具体参数效果，仅记录触发日志 |
| `on_low_hp`（HP < 30%） | 若参数中有 `防御加成 > 0`，则施加一个**永久防御↑**状态（剩余回合 99） |

### 禁止事项

- ❌ **被动技能不能造成伤害**。被动不参与伤害计算。
- ❌ **被动技能的触发时机只有 3 种**：`on_attack`、`on_hit`、`on_low_hp`。引擎内部硬编码。
- ❌ **不能自创被动触发条件**。例如"每回合开始时"、"敌方死亡时"、"换人时"、"HP 高于 50%" 等都不存在。
- ❌ **`on_low_hp` 只有 `防御加成` 会被引擎处理**。其他参数（如攻击加成等）在 on_low_hp 触发时会被忽略。
- ❌ **光环类型目前没有特殊的全队持续生效逻辑**。光环技能放在 passives 里，行为和被动完全一样。

## 七、MP 消耗与冷却规则（硬编码）

| 稀有度 | MP 消耗 | 参考定位 |
|---|---|---|
| N | 0 | 普通攻击（系统兜底技能） |
| 普通 | 5 | 基础技能 |
| 稀有 | 12 | 进阶技能 |
| 史诗 | 20 | 强力技能 |
| 传说 | 32 | 终极技能 |
| 神话 | 45 | 神话技能 |

- MP 消耗由引擎**根据稀有度自动扣除**（硬编码映射）。`消耗MP` 字段的值用于**技能可用性检查**（MP 不足时技能不可选），但实际扣除量是稀有度对应的固定值。因此 `消耗MP` **必须**与稀有度匹配，否则会出现"显示可用但扣了不同数量 MP"的异常。
- 冷却回合数在你填写的值上 +1（引擎内部逻辑），填写 `0` 表示无冷却。
- 全队共享最大回合数：**25 回合**，超过后按剩余总 HP 判定胜负。

### 禁止事项

- ❌ **禁止试图让技能"不消耗MP"**（除了 N 稀有度）。MP 消耗是稀有度锁定的。
- ❌ **禁止设置超过 3 回合的冷却**（建议值）。冷却过长会导致技能几乎无法使用。

## 八、战斗类型（`战斗类型`）的特殊效果

战斗类型是单位级别的被动，不是技能参数能控制的：

| 战斗类型 | 自动效果 | 何时触发 |
|---|---|---|
| 魔导型 | 元素技能伤害 +20% | 造成伤害时 |
| 强攻型 | 造成伤害后回复伤害值 15% 的 MP | 造成伤害时 |
| 重盾型 | 每回合结束回复 3% 最大 HP | 回合结束时 |
| 敏捷型 | 速度追加行动判定（20%保底+速度差加成，上限40%） | 行动后 |
| 均衡型 | 每回合结束回复 5% 最大 MP | 回合结束时 |

### 禁止事项

- ❌ **禁止在技能描述中声称技能能改变战斗类型**。战斗类型是单位固有属性。
- ❌ **禁止技能模仿其他战斗类型的效果**。例如非强攻型技能声称"造成伤害后回复 MP"是无法实现的。

---

## 九、伤害上限

引擎对每次攻击有**伤害上限**（占目标最大 HP 的比例）：

| 克制效果 | 高系数公式（系数>0） | 标准公式 |
|---|---|---|
| 效果拔群 | 38% | 28% |
| 普通 | 22% | 18% |
| 效果不佳 | 16% | 14% |
| 同属性 | 13% | 12% |

最低保底伤害为 6 点。

### 禁止事项

- ❌ **禁止设计"一击必杀/秒杀"技能**。伤害有硬上限。
- ❌ **禁止设计"固定伤害值"技能**。所有伤害都经过公式计算，无法指定"造成 100 点伤害"。
- ❌ **禁止设计"斩杀低血量目标"技能**。不存在斩杀线机制。

## 十、技能设计建议值范围

为了让 AI 生成合理平衡的技能，建议参数遵循以下范围：

| 参数 | 建议范围 |
|---|---|
| 基础威力 | N: 42, 普通: 50~70, 稀有: 70~90, 史诗: 90~120, 传说: 120~160, 神话: 160~200 |
| 命中率 | 0.85 ~ 0.98（不建议低于 0.75） |
| 异常状态概率 | 0.1 ~ 0.4（不建议超过 0.5） |
| 异常状态持续回合 | 1 ~ 4 |
| DoT 伤害比例 | 0.03 ~ 0.08（灼烧/中毒每回合扣血比例） |
| buff/debuff 比例 | 0.1 ~ 0.35（单属性 ±10%~35%） |
| buff/debuff 持续回合 | 2 ~ 4 |
| 暴击率加成 | 0.05 ~ 0.2 |
| 治疗比例 | 0.15 ~ 0.4 |
| 护盾比例 | 0.1 ~ 0.25 |
| 冷却回合 | 0 ~ 3 |
| 吸血比例 | 0.3 ~ 0.6 |

## 十一、总结：AI 绝对不能做的事

1. **不能自创效果公式** — 只能用 7 种预定义公式
2. **不能自创目标类型** — 只能用 5 种预定义目标类型
3. **不能自创参数名** — 只能用本文列出的参数名
4. **不能实现复活、反弹、自爆、驱散、斩杀、真实伤害、偷取MP、禁止换人**
5. **不能一个技能做两件互斥的事**（如同时伤害+治疗，请用吸血公式）
6. **不能绕过MP消耗规则** — MP消耗由稀有度锁定
7. **不能设计一击必杀** — 伤害有百分比上限
8. **不能自创元素属性或克制关系**
9. **不能设计条件自动选择目标** — 目标选择由玩家/AI 决定
10. **不能在被动中实现伤害或复杂的条件触发** — 被动只有 3 种触发时机且效果极其有限
